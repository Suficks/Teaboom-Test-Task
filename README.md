# Карточка товара Teaboom.ru — тестовое задание

Верстка верхней части карточки товара «Ананасовый улун» для интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

- Опубликованная страница: https://teaboom.netlify.app

## Запуск

```bash
npm install
npm run dev      # dev-сервер: http://localhost:5173
npm run build    # production-сборка в папку dist/
npm run preview  # просмотр собранной версии
```

Требуется Node.js 18+.

## Стек

- HTML5, семантическая разметка (`article`, `header`, `figure`, `fieldset`, `nav`)
- SCSS (партиалы, переменные, миксины брейкпоинтов), CSS Grid + Flexbox
- Vanilla JavaScript (ES-модули), без фреймворков и UI-библиотек
- Vite — dev-сервер и сборка

## Структура

```
index.html               разметка страницы
public/logo.svg          логотип, используется в шапке и как favicon
src/
  main.js                точка входа: подключает стили и инициализирует карточку
  js/
    product-card.js      контроллер карточки: переключение фасовки
    format-price.js      форматирование цены (Intl) и расчёт скидки
  scss/
    main.scss            сборка партиалов
    _variables.scss      палитра Teaboom, шрифты, брейкпоинты
    _mixins.scss         медиазапросы, focus-ring
    _base.scss           сброс, типографика, контейнер
    _header.scss         шапка с логотипом
    _breadcrumbs.scss    хлебные крошки
    _product.scss        сетка и элементы карточки
    _packing.scss        выбор фасовки (радио-кнопки)
    _price.scss          блок цены и покупки
    _button.scss         кнопка «В корзину»
  assets/                изображение товара
```

## Как устроено

**Данные фасовок живут в разметке.** Каждая фасовка — нативный `<input type="radio">`
с `data-sku`, `data-price`, `data-old-price`. Без JS страница остаётся полноценной
и доступной (клавиатура, скринридеры); скрипт лишь читает выбранную радио-кнопку
и обновляет цену, старую цену, размер скидки и артикул.

**Адаптивность** — mobile-first, три раскладки через `grid-template-areas`:

- **375 px** — в одну колонку: название и категория над фото, чтобы пользователь сразу
  понимал, что перед ним; фасовки сеткой 2×2; кнопка на всю ширину.
- **768 px** — фото слева (5/12), информация справа; цена и кнопка друг под другом.
- **1440 px** — две равные колонки, цена и кнопка в одну строку, фото фиксируется
  при прокрутке (`position: sticky`).

**Стилистика Teaboom** — шрифт Open Sans, жёлтый акцент `#f5d730`, красная актуальная
цена, серая зачёркнутая старая, кремовый фон описания как у сайдбара на сайте.
